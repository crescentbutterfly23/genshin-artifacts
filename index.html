Or paste text from the “Genshin artifacts to text” Shortcut. Each artifact is checked before anything is added.
How to set up the Shortcut (one time)
  1. Open Shortcuts and tap +Name it “Genshin artifacts to text”.
  2. Add “Select Photos”Tap the arrow on the action and turn on Select Multiple.
  3. Add “Repeat with Each”It repeats with each item in Photos.
  4. Inside the repeat, add “Extract Text from Image”Its input should be Repeat Item.
  5. Still inside, add “Text”Put the Extracted Text variable on the first line, and type ##### on the line below it. This line separates the artifacts.
  6. After “End Repeat”, add “Combine Text”Combine Repeat Results with New Lines.
  7. Add “Copy to Clipboard”Its input is the Combined Text.
Each time: in Genshin, open each artifact in your bag and take a screenshot (setting AssistiveTouch to Screenshot on Single-Tap makes this one tap). Run the Shortcut, select those screenshots, then paste here. You can delete the screenshots afterward.
