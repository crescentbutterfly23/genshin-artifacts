# Working on this repo

- Always merge finished changes into `main` (open a pull request from the working branch and merge it) so they go live on GitHub Pages. No need to ask first.
- `index.html` is the whole app; edit it directly.
- The goal of every feature is the most team damage possible. Main DPS get the best artifacts; supports are built to buff them (team-buff 4-piece sets, ER, buff stats). An artifact that adds no damage anywhere is unnecessary (Discard).
